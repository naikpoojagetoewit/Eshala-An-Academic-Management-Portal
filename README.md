# Eshala Academic Management Portal

## Overview
A MERN Stack Academic Management Portal for managing students, lecturers, courses, attendance, and academic workflows.

## Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js

## Features
- Student Management
- Lecturer Management
- Authentication & Authorization
- Attendance Tracking
- Academic Records Management

## Installation

### Backend
cd backend
npm install
npm start

### Frontend
cd frontend
npm install
npm start
